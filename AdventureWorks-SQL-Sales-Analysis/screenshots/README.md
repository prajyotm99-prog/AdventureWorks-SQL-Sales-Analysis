# Query Screenshots

This folder contains 18 PNG screenshots of SQL query results and exercises completed against the AdventureWorks2019 sample database.

The original screenshot filenames have been preserved to help identify the corresponding exercises. Some filenames describe the question rather than the SQL script, so match screenshots to queries by reviewing their contents.

## How to Use These Screenshots

1. Open the screenshot relevant to the question you're reviewing.
2. Compare the displayed result columns with the corresponding SQL query.
3. Check that the screenshot represents the same query version as the current script.
4. Use the CSV exports in `../results/` when available for easier inspection and further analysis.

## Notes

- Screenshots are supporting evidence of query execution and displayed results.
- They should not replace the SQL scripts as documentation of the query logic.
- Validate numerical findings against the corresponding query output before quoting them in the main README.
- Original filenames are retained for traceability; filenames may be cleaned up later if all links and references are updated.
